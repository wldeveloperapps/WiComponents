# Internacionalización (`@wiloc/ui`)

`@wiloc/ui` **no** incluye diccionarios ES/EN ni copy de producto. La librería expone el **contrato** (inputs de texto + providers `provideWi*I18n`). Las **traducciones viven en la app**.

Usar esta página como **plantilla / checklist** al integrar.

## Principio

| Capa | Responsabilidad |
| ---- | ---------------- |
| `@wiloc/ui` | Comportamiento, a11y, inputs de instancia, providers de locale/chrome |
| App consumidora | Strings, locale, `document.documentElement.lang`, motor i18n (Transloco, etc.) |

Defaults en inglés en providers/inputs son solo fallback técnico, no un locale oficial.

## Checklist por componente

### `wi-input`

| Qué | Dónde |
| --- | ----- |
| Placeholder | input `placeholder` |
| Nombre accesible | `ariaLabel` o `<label for>` + `id` |
| Hint / error | texto en la app + `ariaDescribedBy` |

### `wi-select`

| Qué | Dónde |
| --- | ----- |
| Placeholder | `placeholder` |
| Lista vacía | `emptyText` |
| Limpiar | `clearLabel` (si `clearable`) |
| Quitar chip | `removeChipLabel` |
| Nombre accesible | `ariaLabel` o label asociado |
| Label visible de opciones | datos de la app (`options` / templates) |

### `wi-listbox`

| Qué | Dónde |
| --- | ----- |
| Lista vacía | `emptyText` |
| Nombre accesible | `ariaLabel` / `ariaLabelledBy` o labels proyectados |

### `wi-checkbox` / `wi-switch`

| Qué | Dónde |
| --- | ----- |
| Nombre accesible | `ariaLabel`, `ariaLabelledBy` o `<label>` wrapping / `for`+`id` |
| Hint / error | texto en la app + `ariaDescribedBy` |

### `wi-button`

| Qué | Dónde |
| --- | ----- |
| Texto visible | proyección / contenido de la app |
| Icon-only | `ariaLabel` obligatorio |

### `wi-datepicker`

| Qué | Dónde |
| --- | ----- |
| Placeholder | `placeholder` |
| Limpiar | `clearLabel` |
| Abrir calendario | `calendarLabel` (y/o `ariaLabel`) |
| Hora (etiqueta visible) | `timeLabel` (si `showTime`) |
| Formato hora / minuto | `provideWiCalendarI18n` (`hourPlaceholder`, `minutePlaceholder`, `hourAriaLabel`, `minuteAriaLabel`) |
| Meses, días, prev/next | `provideWiCalendarI18n` |

### `wi-date-range`

Además de lo anterior (reutilizado en cada picker):

| Qué | Dónde |
| --- | ----- |
| Placeholders | `startPlaceholder`, `endPlaceholder` |
| Aria | `startAriaLabel`, `endAriaLabel` |
| Abrir calendarios | `startCalendarLabel`, `endCalendarLabel` |
| Limpiar / hora | `clearLabel`, `timeLabel` |

Demo interactiva: **Forms → WiDatepicker → Locale (app-provided)**.

### `wi-table` / `wi-data-pagination` / `wi-column-visibility`

| Qué | Dónde |
| --- | ----- |
| Vacío, paginación, filtros, columnas, operadores | `provideWiDataDisplayI18n` |
| Override puntual | inputs opcionales (`emptyMessage`, `previousLabel`, …) |
| Cabeceras / options de filtro | `WiColumnDef` (app) |

### `wi-dialog`

| Qué | Dónde |
| --- | ----- |
| Título / descripción / acciones | proyección (`wi-dialog-title`, …) |
| Aria del botón X | `provideWiOverlaysI18n` (`dialogCloseLabel`) o input `closeLabel` |

### `wi-tabs`

No hay inputs de label en la librería: el copy es **contenido proyectado** de la app.

| Qué | Dónde |
| --- | ----- |
| Título visible de cada pestaña | Texto (u otro contenido) dentro de `button[wiTabsTrigger]` |
| Nombre accesible | Ese mismo texto, o `aria-label` en el `button` si el trigger es solo icono |
| Contenido del panel | Markup dentro de `[wiTabsContent]` (también de la app) |

Las claves (`wiTabsTrigger` / `wiTabsContent` / `value`) las define la app; la librería no impone IDs ni copy. Solo se localizan títulos y cuerpo.

```html
<wi-tabs [(value)]="activeTabId">
  <wi-tabs-list>
    @for (tab of tabs; track tab.id) {
      <button type="button" [wiTabsTrigger]="tab.id">{{ tab.label }}</button>
    }
  </wi-tabs-list>
  @for (tab of tabs; track tab.id) {
    <div [wiTabsContent]="tab.id">{{ tab.body }}</div>
  }
</wi-tabs>
```

Demo smoke: **e2e-consumer** (IDs + copy de la app; toggle ES/EN).

## Plantilla `provideWiCalendarI18n`

Registrar en `app.config.ts` (o equivalente). Las funciones se evalúan al renderizar el calendario: pueden leer un signal/locale de la app.

```ts
import { provideWiCalendarI18n } from '@wiloc/ui/forms';
import type { WiMonthLabels } from '@wiloc/ui/forms';

const MONTHS_ES: WiMonthLabels = [
  'Enero', 'Febrero', 'Marzo', 'Abril', 'Mayo', 'Junio',
  'Julio', 'Agosto', 'Septiembre', 'Octubre', 'Noviembre', 'Diciembre',
];

provideWiCalendarI18n({
  firstDayOfWeek: () => 1, // lunes
  months: () => MONTHS_ES,
  formatMonth: (month) => MONTHS_ES[month],
  formatYear: (year) => String(year),
  formatHeader: (month, year) => `${MONTHS_ES[month]} ${year}`,
  formatWeekdayName: (index) => ['Do', 'Lu', 'Ma', 'Mi', 'Ju', 'Vi', 'Sá'][index % 7] ?? '',
  labelWeekday: (index) =>
    ['Domingo', 'Lunes', 'Martes', 'Miércoles', 'Jueves', 'Viernes', 'Sábado'][index % 7] ?? '',
  labelPrevious: () => 'Mes anterior',
  labelNext: () => 'Mes siguiente',
  hourPlaceholder: () => 'HH',
  minutePlaceholder: () => 'MM',
  hourAriaLabel: () => 'Hora',
  minuteAriaLabel: () => 'Minuto',
});
```

Campos de `WiCalendarI18n` (todos opcionales en el `Partial`; completar los que la app necesite):

- `firstDayOfWeek`
- `months` / `formatMonth` / `formatYear` / `formatHeader`
- `formatWeekdayName` / `labelWeekday`
- `labelPrevious` / `labelNext`
- `years` (lista de años del selector, si aplica)
- `hourPlaceholder` / `minutePlaceholder` / `hourAriaLabel` / `minuteAriaLabel` (formato de hora si `showTime`)

## Plantilla `provideWiDataDisplayI18n`

```ts
import { provideWiDataDisplayI18n } from '@wiloc/ui/data-display';

provideWiDataDisplayI18n({
  emptyMessage: () => 'No hay datos',
  tableAriaLabel: () => 'Tabla de datos',
  paginationAriaLabel: () => 'Paginación',
  previousLabel: () => 'Anterior',
  nextLabel: () => 'Siguiente',
  filterPlaceholder: () => 'Escribir para buscar',
  selectPlaceholder: () => 'Seleccionar uno',
  filterOperatorAriaLabel: () => 'Operador de filtro',
  filterAriaLabel: (header) => `Filtrar ${header}`,
  columnVisibilitySummary: () => '{visible} de {total} columnas visibles',
  columnVisibilityMenuLabel: () => 'Columnas',
  columnVisibilityAriaLabel: () => 'Visibilidad de columnas',
  resultCountTemplate: () => '{count} resultados',
  rowActionsHeader: () => 'Acciones',
  filterOperators: () => [
    { value: 'contains', label: 'Contiene' },
    { value: 'notContains', label: 'No contiene' },
    { value: 'startsWith', label: 'Empieza por' },
    { value: 'endsWith', label: 'Termina en' },
    { value: 'equals', label: 'Igual a' },
    { value: 'notEquals', label: 'Distinto de' },
    { value: 'none', label: 'Sin filtro' },
  ],
});
```

## Snippet de template (app)

```html
<label for="hire-date">Fecha de alta</label>
<wi-datepicker
  id="hire-date"
  [(value)]="hireDate"
  clearable
  placeholder="Selecciona una fecha…"
  clearLabel="Limpiar"
  calendarLabel="Abrir calendario"
  ariaLabel="Fecha de alta"
/>
```

Con hora:

```html
<wi-datepicker
  [(value)]="appointment"
  showTime
  timeLabel="Hora"
  placeholder="Fecha y hora…"
  ariaLabel="Cita"
/>
```

## Qué no hacer

- No hardcodear idiomas de producto dentro de `@wiloc/ui`.
- No asumir que Storybook o el monorepo sustituyen el i18n de la app.
- No dejar botones solo-icono sin `ariaLabel` / `clearLabel` traducidos.

Referencia de consumo empaquetado: `apps/e2e-consumer` (toggle ES/EN + `.tgz`).
