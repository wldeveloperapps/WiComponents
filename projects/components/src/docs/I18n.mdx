# Internacionalización (`@wiloc/ui`)

`@wiloc/ui` **no** trae diccionarios ES/EN. La app traduce; la librería solo expone **dónde** enganchar el copy.

## Cómo se implementa en la app (resumen)

Hay **dos canales**. Ambos los rellena la app con su motor i18n (Transloco, ngx-translate, signals, JSON, …).

```text
┌─────────────────────────────────────────────────────────────┐
│  App consumidora                                            │
│                                                             │
│  1. app.config.ts  →  provideWi*I18n({ … })                 │
│     Chrome compartido (meses del calendario, “Anterior”,    │
│     aria del botón X del dialog, operadores de filtro, …)   │
│                                                             │
│  2. Template       →  [placeholder]="t('…')"                │
│     Copy de esa instancia (placeholder, ariaLabel, título)  │
└─────────────────────────────────────────────────────────────┘
```

| Canal | Qué | Dónde se configura | Ejemplo |
| ----- | --- | ------------------ | ------- |
| **Provider** | Labels de chrome reutilizados por todos los componentes del dominio | `app.config.ts` → `provideWiCalendarI18n` / `provideWiDataDisplayI18n` / `provideWiOverlaysI18n` | Meses, “Mes anterior”, “Cerrar” (dialog), “Cerrar notificación” / “Notificaciones” (toast), “Anterior/Siguiente” de paginación |
| **Input** | Copy de **esta** instancia en pantalla | Template / binding | `placeholder`, `clearLabel`, `ariaLabel`, cabeceras de columna, título del dialog |

**Regla práctica**

- Si el texto es del **chrome del control** (navegación del calendario, paginación, botón X) → **provider**.
- Si el texto es del **caso de uso** (placeholder “Fecha de alta”, título “Editar sitio”) → **input** (o proyección de contenido).

Referencia runnable: `apps/e2e-consumer` (`locale.ts` + `app.config.ts` + bindings en `app.html`).

## Paso a paso

### 1. Registrar providers en `app.config.ts`

Una vez por app. Las funciones se evalúan al renderizar: pueden leer el locale actual (signal, Transloco, …).

```ts
// app.config.ts
import { ApplicationConfig } from '@angular/core';
import { provideWiDataDisplayI18n } from '@wiloc/ui/data-display';
import { provideWiCalendarI18n } from '@wiloc/ui/forms';
import { provideWiOverlaysI18n } from '@wiloc/ui/overlays';
import { createCalendarI18n, createDataDisplayI18n, createOverlaysI18n } from './locale';

export const appConfig: ApplicationConfig = {
  providers: [
    // …otros providers
    provideWiCalendarI18n(createCalendarI18n()),
    provideWiDataDisplayI18n(createDataDisplayI18n()),
    provideWiOverlaysI18n(createOverlaysI18n()),
  ],
};
```

### 2. Definir las factories (leen el locale en cada llamada)

Patrón mínimo (como en e2e-consumer). Con Transloco, dentro de cada `() =>` llama a `translate('key')`.

```ts
// locale.ts (app)
import { signal } from '@angular/core';
import type { WiCalendarI18n, WiMonthLabels } from '@wiloc/ui/forms';
import type { WiDataDisplayI18n } from '@wiloc/ui/data-display';
import type { WiOverlaysI18n } from '@wiloc/ui/overlays';

export type AppLocale = 'es' | 'en';
export const appLocale = signal<AppLocale>('es');

const MONTHS: Record<AppLocale, WiMonthLabels> = {
  es: ['Enero', 'Febrero', /* … */ 'Diciembre'],
  en: ['January', 'February', /* … */ 'December'],
};

export function createCalendarI18n(): Partial<WiCalendarI18n> {
  return {
    firstDayOfWeek: () => 1,
    months: () => MONTHS[appLocale()],
    formatMonth: (m) => MONTHS[appLocale()][m],
    formatYear: (y) => String(y),
    formatHeader: (m, y) => `${MONTHS[appLocale()][m]} ${y}`,
    formatWeekdayName: (i) =>
      (appLocale() === 'es'
        ? ['Do', 'Lu', 'Ma', 'Mi', 'Ju', 'Vi', 'Sá']
        : ['Su', 'Mo', 'Tu', 'We', 'Th', 'Fr', 'Sa'])[i % 7] ?? '',
    labelWeekday: (i) =>
      (appLocale() === 'es'
        ? ['Domingo', 'Lunes', 'Martes', 'Miércoles', 'Jueves', 'Viernes', 'Sábado']
        : ['Sunday', 'Monday', 'Tuesday', 'Wednesday', 'Thursday', 'Friday', 'Saturday'])[i % 7] ?? '',
    labelPrevious: () => (appLocale() === 'es' ? 'Mes anterior' : 'Previous month'),
    labelNext: () => (appLocale() === 'es' ? 'Mes siguiente' : 'Next month'),
    hourPlaceholder: () => 'HH',
    minutePlaceholder: () => 'MM',
    hourAriaLabel: () => (appLocale() === 'es' ? 'Hora' : 'Hour'),
    minuteAriaLabel: () => (appLocale() === 'es' ? 'Minuto' : 'Minute'),
  };
}

export function createOverlaysI18n(): Partial<WiOverlaysI18n> {
  return {
    dialogCloseLabel: () => (appLocale() === 'es' ? 'Cerrar' : 'Close'),
    confirmCancelLabel: () => (appLocale() === 'es' ? 'Cancelar' : 'Cancel'),
    toastCloseLabel: () => (appLocale() === 'es' ? 'Cerrar notificación' : 'Close toast'),
    toastRegionLabel: () => (appLocale() === 'es' ? 'Notificaciones' : 'Notifications'),
  };
}

// createDataDisplayI18n(): igual — emptyMessage, previousLabel, filterOperators, …
```

Al cambiar el idioma: actualiza `appLocale` (o el motor i18n) y `document.documentElement.lang`. No hace falta re-registrar los providers.

### 3. Bindings de instancia en el template

El provider **no** traduce el placeholder ni el título del dialog. Eso va en el template:

```html
<!-- Con tu helper / pipe de i18n -->
<label [for]="hireDateId">{{ t('hireDate.label') }}</label>
<wi-datepicker
  [id]="hireDateId"
  [(value)]="hireDate"
  clearable
  [placeholder]="t('hireDate.placeholder')"
  [clearLabel]="t('hireDate.clear')"
  [calendarLabel]="t('hireDate.openCalendar')"
  [ariaLabel]="t('hireDate.aria')"
/>
```

Sin motor i18n (solo para entender el contrato):

```html
<wi-datepicker
  [(value)]="hireDate"
  clearable
  placeholder="Selecciona una fecha…"
  clearLabel="Limpiar"
  calendarLabel="Abrir calendario"
  ariaLabel="Fecha de alta"
/>
```

Con hora:

```html
<wi-datepicker
  [(value)]="appointment"
  showTime
  [timeLabel]="t('appointment.time')"
  [placeholder]="t('appointment.placeholder')"
  [ariaLabel]="t('appointment.aria')"
/>
```

## Qué va en cada canal (por componente)

### Solo inputs / proyección (sin provider propio)

| Componente | Labels vía input / contenido |
| ---------- | ---------------------------- |
| `wi-input` | `placeholder`, `ariaLabel`, hint/error + `ariaDescribedBy` |
| `wi-select` | `placeholder`, `emptyText`, `clearLabel`, `removeChipLabel`, `ariaLabel` |
| `wi-listbox` | `emptyText`, `ariaLabel` / `ariaLabelledBy` |
| `wi-checkbox` / `wi-switch` | `ariaLabel` / label wrapping |
| `wi-button` | proyección; icon-only → `ariaLabel` |
| `wi-tabs` | texto dentro de `button[wiTabsTrigger]` y del panel |

### `wi-datepicker` / `wi-date-range`

| Qué | Canal |
| --- | ----- |
| Placeholder, clear, abrir calendario, `timeLabel`, aria | **Inputs** |
| Meses, días, prev/next, placeholders HH/MM | **`provideWiCalendarI18n`** |

`wi-date-range` añade `startPlaceholder` / `endPlaceholder` / `startAriaLabel` / `endAriaLabel` (también inputs).

Demo: **Forms → WiDatepicker** + toolbar **Locale**.

### `wi-table` / paginación / columnas

| Qué | Canal |
| --- | ----- |
| Vacío, paginación, filtros, operadores, “Columnas” | **`provideWiDataDisplayI18n`** |
| Override puntual | inputs opcionales (`emptyMessage`, `previousLabel`, …) |
| Cabeceras y options de filtro | `WiColumnDef` (app) |

### `wi-dialog`

| Qué | Canal |
| --- | ----- |
| Título, descripción, acciones | **Proyección** (`wi-dialog-title`, …) |
| Aria del botón X | **`provideWiOverlaysI18n`** (`dialogCloseLabel`) o input `closeLabel` |

### `wi-toast` / `wi-toaster`

| Qué | Canal |
| --- | ----- |
| Título, descripción, action/cancel, promise | **API** (`wiToast` / `WiToast` — la app) |
| Aria botón cerrar / región | **`provideWiOverlaysI18n`** (`toastCloseLabel`, `toastRegionLabel`) |

Demo: **Overlays → WiToast** (Canvas) + toolbar **Locale**.

## Plantillas de providers (checklist de campos)

### `provideWiCalendarI18n`

```ts
import { provideWiCalendarI18n } from '@wiloc/ui/forms';
import type { WiMonthLabels } from '@wiloc/ui/forms';

const MONTHS_ES: WiMonthLabels = [
  'Enero', 'Febrero', 'Marzo', 'Abril', 'Mayo', 'Junio',
  'Julio', 'Agosto', 'Septiembre', 'Octubre', 'Noviembre', 'Diciembre',
];

provideWiCalendarI18n({
  firstDayOfWeek: () => 1,
  months: () => MONTHS_ES,
  formatMonth: (month) => MONTHS_ES[month],
  formatYear: (year) => String(year),
  formatHeader: (month, year) => `${MONTHS_ES[month]} ${year}`,
  formatWeekdayName: (index) => ['Do', 'Lu', 'Ma', 'Mi', 'Ju', 'Vi', 'Sá'][index % 7] ?? '',
  labelWeekday: (index) =>
    ['Domingo', 'Lunes', 'Martes', 'Miércoles', 'Jueves', 'Viernes', 'Sábado'][index % 7] ?? '',
  labelPrevious: () => 'Mes anterior',
  labelNext: () => 'Mes siguiente',
  hourPlaceholder: () => 'HH',
  minutePlaceholder: () => 'MM',
  hourAriaLabel: () => 'Hora',
  minuteAriaLabel: () => 'Minuto',
});
```

Campos opcionales (`Partial<WiCalendarI18n>`): `firstDayOfWeek`, `months`, `formatMonth`, `formatYear`, `formatHeader`, `formatWeekdayName`, `labelWeekday`, `labelPrevious`, `labelNext`, `years`, `hourPlaceholder`, `minutePlaceholder`, `hourAriaLabel`, `minuteAriaLabel`.

```ts
});
```

## Ejemplo `wi-tabs` (solo proyección)

```html
<wi-tabs [(value)]="activeTabId">
  <wi-tabs-list>
    @for (tab of tabs; track tab.id) {
      <button type="button" [wiTabsTrigger]="tab.id">{{ tab.label }}</button>
    }
  </wi-tabs-list>
  @for (tab of tabs; track tab.id) {
    <div [wiTabsContent]="tab.id">{{ tab.body }}</div>
  }
</wi-tabs>
```

`tabs` sale del i18n de la app; la librería no impone copy.

## Qué no hacer

- No meter diccionarios de producto dentro de `@wiloc/ui`.
- No esperar que el selector **Locale** de Storybook sustituya el i18n de la app (solo simula providers + demos).
- No dejar botones solo-icono sin `ariaLabel` / `clearLabel` traducidos.
- No poner el placeholder del datepicker en el provider: va en el **input** `placeholder`.
