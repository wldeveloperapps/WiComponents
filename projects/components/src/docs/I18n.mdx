# Internacionalización (`@wiloc/ui`)

Instalación del paquete, CSS y providers de iconos: **Instalación**.

`@wiloc/ui` **no** trae diccionarios ES/EN. La app traduce; la librería solo expone **dónde** enganchar el copy.

## Cómo se implementa en la app (resumen)

Hay **dos canales**. Ambos los rellena la app con su motor i18n (Transloco, ngx-translate, signals, JSON, …).

```text
┌─────────────────────────────────────────────────────────────┐
│  App consumidora                                            │
│                                                             │
│  1. app.config.ts  →  provideWi*I18n({ … })                 │
│     Chrome compartido (meses del calendario, “Anterior”,    │
│     aria del botón X del dialog, operadores de filtro, …)   │
│                                                             │
│  2. Template       →  [placeholder]="t('…')"                │
│     Copy de esa instancia (placeholder, ariaLabel, título)  │
└─────────────────────────────────────────────────────────────┘
```

| Canal | Qué | Dónde se configura | Ejemplo |
| ----- | --- | ------------------ | ------- |
| **Provider** | Labels de chrome reutilizados por todos los componentes del dominio | `app.config.ts` → `provideWiCalendarI18n` / `provideWiDataDisplayI18n` / `provideWiOverlaysI18n` | Meses, “Mes anterior”, “Cerrar” (dialog), “Cerrar notificación” / “Notificaciones” (toast), “Anterior/Siguiente” de paginación |
| **Input** | Copy de **esta** instancia en pantalla | Template / binding | `placeholder`, `clearLabel`, `ariaLabel`, cabeceras de columna, título del dialog |

**Regla práctica**

- Si el texto es del **chrome del control** (navegación del calendario, paginación, botón X) → **provider**.
- Si el texto es del **caso de uso** (placeholder “Fecha de alta”, título “Editar sitio”) → **input** (o proyección de contenido).

Referencia runnable sin Transloco: `apps/e2e-consumer` (`locale.ts` + `app.config.ts` + bindings en `app.html`).  
Apps Wiloc con Transloco: sección **Transloco** más abajo.

## Transloco (recomendado en apps de producto)

Las apps Wiloc ya usan Transloco. **No dupliques** ES/EN en TypeScript: el chrome de Wi llama a `translate()` al pintar.

### Dónde va cada cosa

| Qué | Dónde | No |
| --- | ----- | -- |
| Claves `wi.calendar` / `wi.table` / `wi.overlays` | `src/assets/i18n/es.json` y `en.json` (los JSON que ya carga Transloco) | No crear una carpeta aparte ni meter `.ts` ahí |
| Factories `create*I18n` + `provideAppWiI18n()` | `src/app/locale.ts` (o similar) | No pongas este archivo en `assets/i18n/` |
| Copy de pantalla (placeholder, título de dialog, cabeceras) | Template: `{{ 'clave' \| transloco }}` | No va en `provideWi*I18n` |

`assets/i18n` solo sirve JSON. Transloco no ejecuta TypeScript.

`provideWi*I18n(createX())` se evalúa al cargar `app.config.ts`, **sin** `inject()`. Captura `TranslocoService` en un `ENVIRONMENT_INITIALIZER`; las funciones `() => t('…')` se ejecutan al renderizar, con el idioma activo.

`en.json` (mismas claves): January…December; Su/Mo/Tu/We/Th/Fr/Sa; Sunday…Saturday; Previous month; Next month; Hour; Minute; No data; Data table; Pagination; Previous; Next; Type to search; Select one; Filter operator; `Filter {{header}}`; `{visible} of {total} columns visible`; Columns; Column visibility; `{count} results`; Actions; Contains / Does not contain / Starts with / Ends with / Equals / Does not equal / No filter; Close; Cancel; Close toast; Notifications.

### `src/app/locale.ts`

El import de Transloco es el de la app (`@jsverse/transloco` o `@ngneat/transloco`).

```ts
import { ENVIRONMENT_INITIALIZER, inject, type Provider } from '@angular/core';
import { TranslocoService } from '@jsverse/transloco';
import {
  provideWiDataDisplayI18n,
  type WiDataDisplayI18n,
} from '@wiloc/ui/data-display';
import {
  provideWiCalendarI18n,
  type WiCalendarI18n,
  type WiMonthLabels,
} from '@wiloc/ui/forms';
import { provideWiOverlaysI18n, type WiOverlaysI18n } from '@wiloc/ui/overlays';

let transloco: TranslocoService;

function t(key: string, params?: Record<string, unknown>): string {
  return transloco.translate(key, params);
}

export function provideAppWiI18n(): Provider[] {
  return [
    {
      provide: ENVIRONMENT_INITIALIZER,
      multi: true,
      useFactory: () => {
        const service = inject(TranslocoService);
        return () => {
          transloco = service;
        };
      },
    },
    ...provideWiCalendarI18n(createCalendarI18n()),
    provideWiDataDisplayI18n(createDataDisplayI18n()),
    provideWiOverlaysI18n(createOverlaysI18n()),
  ];
}

function createCalendarI18n(): Partial<WiCalendarI18n> {
  return {
    firstDayOfWeek: () => 1,
    months: () =>
      Array.from({ length: 12 }, (_, i) => t(`wi.calendar.months.${i}`)) as WiMonthLabels,
    formatMonth: (month) => t(`wi.calendar.months.${month}`),
    formatYear: (year) => String(year),
    formatHeader: (month, year) => `${t(`wi.calendar.months.${month}`)} ${year}`,
    formatWeekdayName: (index) => t(`wi.calendar.weekdaysShort.${index % 7}`),
    labelWeekday: (index) => t(`wi.calendar.weekdaysLong.${index % 7}`),
    labelPrevious: () => t('wi.calendar.previous'),
    labelNext: () => t('wi.calendar.next'),
    years: (startYear, endYear) => {
      const start = startYear ?? new Date().getFullYear() - 10;
      const end = endYear ?? new Date().getFullYear() + 10;
      return Array.from({ length: end - start + 1 }, (_, i) => start + i);
    },
    hourPlaceholder: () => 'HH',
    minutePlaceholder: () => 'MM',
    hourAriaLabel: () => t('wi.calendar.hour'),
    minuteAriaLabel: () => t('wi.calendar.minute'),
  };
}

function createDataDisplayI18n(): Partial<WiDataDisplayI18n> {
  return {
    emptyMessage: () => t('wi.table.empty'),
    tableAriaLabel: () => t('wi.table.aria'),
    paginationAriaLabel: () => t('wi.table.paginationAria'),
    previousLabel: () => t('wi.table.previous'),
    nextLabel: () => t('wi.table.next'),
    filterPlaceholder: () => t('wi.table.filterPlaceholder'),
    selectPlaceholder: () => t('wi.table.selectPlaceholder'),
    filterOperatorAriaLabel: () => t('wi.table.filterOperatorAria'),
    filterAriaLabel: (header) => t('wi.table.filterAria', { header }),
    columnVisibilitySummary: () => t('wi.table.columnSummary'),
    columnVisibilityMenuLabel: () => t('wi.table.columnMenu'),
    columnVisibilityAriaLabel: () => t('wi.table.columnAria'),
    resultCountTemplate: () => t('wi.table.resultCount'),
    rowActionsHeader: () => t('wi.table.rowActions'),
    expandColumnHeader: () => t('wi.table.expandColumn'),
    expandRowAriaLabel: () => t('wi.table.expandRow'),
    collapseRowAriaLabel: () => t('wi.table.collapseRow'),
    filterOperators: () => [
      { value: 'contains', label: t('wi.table.operators.contains') },
      { value: 'notContains', label: t('wi.table.operators.notContains') },
      { value: 'startsWith', label: t('wi.table.operators.startsWith') },
      { value: 'endsWith', label: t('wi.table.operators.endsWith') },
      { value: 'equals', label: t('wi.table.operators.equals') },
      { value: 'notEquals', label: t('wi.table.operators.notEquals') },
      { value: 'none', label: t('wi.table.operators.none') },
    ],
  };
}

function createOverlaysI18n(): Partial<WiOverlaysI18n> {
  return {
    dialogCloseLabel: () => t('wi.overlays.dialogClose'),
    confirmCancelLabel: () => t('wi.overlays.confirmCancel'),
    toastCloseLabel: () => t('wi.overlays.toastClose'),
    toastRegionLabel: () => t('wi.overlays.toastRegion'),
  };
}
```

### `app.config.ts`

`provideTransloco(...)` **antes** que `provideAppWiI18n()`:

```ts
import { provideAppWiI18n } from './locale';

export const appConfig: ApplicationConfig = {
  providers: [
    provideTransloco({ /* config existente de la app */ }),
    provideAppWiI18n(),
  ],
};
```

Al cambiar idioma (`setActiveLang('en')`) no hace falta re-registrar providers. Opcional: `document.documentElement.lang = lang`.

## Sin Transloco (signals / e2e-consumer)

### 1. Registrar providers en `app.config.ts`

Una vez por app. Las funciones se evalúan al renderizar: pueden leer el locale actual (signal, Transloco, …).

```ts
// app.config.ts
import { ApplicationConfig } from '@angular/core';
import { provideWiDataDisplayI18n } from '@wiloc/ui/data-display';
import { provideWiCalendarI18n } from '@wiloc/ui/forms';
import { provideWiOverlaysI18n } from '@wiloc/ui/overlays';
import { createCalendarI18n, createDataDisplayI18n, createOverlaysI18n } from './locale';

export const appConfig: ApplicationConfig = {
  providers: [
    // …otros providers
    provideWiCalendarI18n(createCalendarI18n()),
    provideWiDataDisplayI18n(createDataDisplayI18n()),
    provideWiOverlaysI18n(createOverlaysI18n()),
  ],
};
```

### 2. Definir las factories (leen el locale en cada llamada)

Patrón de `e2e-consumer` (sin Transloco). Si la app usa Transloco, usa la sección anterior, no este diccionario en TS.

```ts
// locale.ts (app)
import { signal } from '@angular/core';
import type { WiCalendarI18n, WiMonthLabels } from '@wiloc/ui/forms';
import type { WiDataDisplayI18n } from '@wiloc/ui/data-display';
import type { WiOverlaysI18n } from '@wiloc/ui/overlays';

export type AppLocale = 'es' | 'en';
export const appLocale = signal<AppLocale>('es');

const MONTHS: Record<AppLocale, WiMonthLabels> = {
  es: ['Enero', 'Febrero', /* … */ 'Diciembre'],
  en: ['January', 'February', /* … */ 'December'],
};

export function createCalendarI18n(): Partial<WiCalendarI18n> {
  return {
    firstDayOfWeek: () => 1,
    months: () => MONTHS[appLocale()],
    formatMonth: (m) => MONTHS[appLocale()][m],
    formatYear: (y) => String(y),
    formatHeader: (m, y) => `${MONTHS[appLocale()][m]} ${y}`,
    formatWeekdayName: (i) =>
      (appLocale() === 'es'
        ? ['Do', 'Lu', 'Ma', 'Mi', 'Ju', 'Vi', 'Sá']
        : ['Su', 'Mo', 'Tu', 'We', 'Th', 'Fr', 'Sa'])[i % 7] ?? '',
    labelWeekday: (i) =>
      (appLocale() === 'es'
        ? ['Domingo', 'Lunes', 'Martes', 'Miércoles', 'Jueves', 'Viernes', 'Sábado']
        : ['Sunday', 'Monday', 'Tuesday', 'Wednesday', 'Thursday', 'Friday', 'Saturday'])[i % 7] ?? '',
    labelPrevious: () => (appLocale() === 'es' ? 'Mes anterior' : 'Previous month'),
    labelNext: () => (appLocale() === 'es' ? 'Mes siguiente' : 'Next month'),
    hourPlaceholder: () => 'HH',
    minutePlaceholder: () => 'MM',
    hourAriaLabel: () => (appLocale() === 'es' ? 'Hora' : 'Hour'),
    minuteAriaLabel: () => (appLocale() === 'es' ? 'Minuto' : 'Minute'),
  };
}

export function createOverlaysI18n(): Partial<WiOverlaysI18n> {
  return {
    dialogCloseLabel: () => (appLocale() === 'es' ? 'Cerrar' : 'Close'),
    confirmCancelLabel: () => (appLocale() === 'es' ? 'Cancelar' : 'Cancel'),
    toastCloseLabel: () => (appLocale() === 'es' ? 'Cerrar notificación' : 'Close toast'),
    toastRegionLabel: () => (appLocale() === 'es' ? 'Notificaciones' : 'Notifications'),
  };
}

// createDataDisplayI18n(): igual — emptyMessage, previousLabel, filterOperators, …
```

Al cambiar el idioma: actualiza `appLocale` (o el motor i18n) y `document.documentElement.lang`. No hace falta re-registrar los providers.

### 3. Bindings de instancia en el template

El provider **no** traduce el placeholder ni el título del dialog. Eso va en el template:

```html
<!-- Con tu helper / pipe de i18n -->
<label [for]="hireDateId">{{ t('hireDate.label') }}</label>
<wi-datepicker
  [id]="hireDateId"
  [(value)]="hireDate"
  clearable
  [placeholder]="t('hireDate.placeholder')"
  [clearLabel]="t('hireDate.clear')"
  [calendarLabel]="t('hireDate.openCalendar')"
  [ariaLabel]="t('hireDate.aria')"
/>
```

Sin motor i18n (solo para entender el contrato):

```html
<wi-datepicker
  [(value)]="hireDate"
  clearable
  placeholder="Selecciona una fecha…"
  clearLabel="Limpiar"
  calendarLabel="Abrir calendario"
  ariaLabel="Fecha de alta"
/>
```

Con hora:

```html
<wi-datepicker
  [(value)]="appointment"
  showTime
  [timeLabel]="t('appointment.time')"
  [placeholder]="t('appointment.placeholder')"
  [ariaLabel]="t('appointment.aria')"
/>
```

## Qué va en cada canal (por componente)

### Solo inputs / proyección (sin provider propio)

| Componente | Labels vía input / contenido |
| ---------- | ---------------------------- |
| `wi-input` | `placeholder`, `ariaLabel`, hint/error + `ariaDescribedBy` |
| `wi-select` | `placeholder`, `emptyText`, `clearLabel`, `removeChipLabel`, `ariaLabel` |
| `wi-listbox` | `emptyText`, `ariaLabel` / `ariaLabelledBy` |
| `wi-checkbox` / `wi-switch` | `ariaLabel` / label wrapping |
| `button[wiButton]` | proyección; icon-only → `ariaLabel` |
| `wi-tabs` | texto dentro de `button[wiTabsTrigger]` y del panel |
| `wi-breadcrumb` | `items[].label`, `ariaLabel` |

### `wi-datepicker` / `wi-date-range`

| Qué | Canal |
| --- | ----- |
| Placeholder, clear, abrir calendario, `timeLabel`, aria | **Inputs** |
| Meses, días, prev/next, placeholders HH/MM | **`provideWiCalendarI18n`** |

`wi-date-range` añade `startPlaceholder` / `endPlaceholder` / `startAriaLabel` / `endAriaLabel` (también inputs).

Demo: **Forms → WiDatepicker** + toolbar **Locale**.

### `wi-table` / paginación / columnas

| Qué | Canal |
| --- | ----- |
| Vacío, paginación, filtros, operadores, “Columnas”, expand compacto | **`provideWiDataDisplayI18n`** |
| Override puntual | inputs opcionales (`emptyMessage`, `previousLabel`, …) |
| Cabeceras y options de filtro | `WiColumnDef` (app) |

### `wi-dialog`

| Qué | Canal |
| --- | ----- |
| Título, descripción, acciones | **Proyección** (`wi-dialog-title`, …) |
| Aria del botón X | **`provideWiOverlaysI18n`** (`dialogCloseLabel`) o input `closeLabel` |

### `wi-toast` / `wi-toaster`

| Qué | Canal |
| --- | ----- |
| Título, descripción, action/cancel, promise | **API** (`wiToast` / `WiToast` — la app) |
| Aria botón cerrar / región | **`provideWiOverlaysI18n`** (`toastCloseLabel`, `toastRegionLabel`) |

Demo: **Overlays → WiToast** (Canvas) + toolbar **Locale**.

### `wi-breadcrumb`

| Qué | Canal |
| --- | ----- |
| Labels, rutas, iconos | **`items`** (`label`, `href?`, `icon?`) |
| Nombre del landmark | **Input** `ariaLabel` |

```html
<wi-breadcrumb
  [items]="crumbs"
  [ariaLabel]="t('breadcrumb.aria')"
  (itemClick)="onCrumb($event)"
/>
```

`crumbs[].label` y `ariaLabel` salen del i18n de la app; la librería no impone copy.

Demo: **Navigation → WiBreadcrumb** + toolbar **Locale**.

## Qué no hacer

- No meter diccionarios de producto dentro de `@wiloc/ui`.
- No poner `locale.ts` en `src/assets/i18n/` (solo JSON de Transloco).
- No duplicar ES/EN en TypeScript si la app ya tiene Transloco: las claves `wi.*` van en `es.json` / `en.json`.
- No esperar que el selector **Locale** de Storybook sustituya el i18n de la app (solo simula providers + demos).
- No dejar botones solo-icono sin `ariaLabel` / `clearLabel` traducidos.
- No poner el placeholder del datepicker en el provider: va en el **input** `placeholder`.
